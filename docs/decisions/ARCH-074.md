### ARCH-074 — Cue polish: Setup / Action / Feel, 30 rewritten, thumbnails in the picker, the Builder and /check
Date: 2026-11-15 | Status: Accepted (founder direction, 2026-11-15) | Engine unchanged, calibration unchanged, coach parity 19/24 | Reversible: Yes (one additive nullable column; UI only).
Amends ARCH-072 items 2 and 4 and reverses ARCH-073's "no pictures in the Builder or on /check".

1. **Shape.** A cue is `{ kind: "setup" | "action" | "feel", text }[]`. The existing `cues String[]` column cannot hold it and a column-type change was ruled out, so an additive `Exercise.cueSteps Json?` (migration `add_exercise_cue_steps`) carries it. `cues.ts` stays the source of truth; the seed writes `cueSteps` and keeps `cues` filled with the same text so the old column can be dropped later. `ExerciseRecord.cues` is now `CueStep[]`: `cueSteps` when it has a well-formed step, else each legacy line as an "action" step, so a deploy before the reseed still shows cues. Deploy order is unchanged: migrate, then seed.
2. **Content.** 30 exercises (the ones used by two or more of the six /check presets, plus Dumbbell Row, Dumbbell Curl, Push-Up, Plank, Cable Chest Fly) are `written(setup, action, feel)`, read and approved by the founder, so they ship reviewed (no "(beta)"). The other 80 are `draft(...)`: their lines as "action" steps, still beta, not rewritten. Four vague draft lines were fixed (Pendulum Squat, Smith Machine Squat, Incline Barbell Bench Press, Ab Wheel Rollout); the 29 draft exercises with no feel line wait for the later rewrite.
3. **Rules, relaxed from ARCH-072.** Movement directives, negatives ("no shrug", "keep your chest proud") and mind-muscle or pump language are allowed. Still no safety, medical or outcome language. Lint adds `build*`, `maxim*`, `target(s)`, `grow*`, `gain(s)` to the shared list and the ARCH-072 stems. Length is per kind (setup 110, action 110, feel 120 characters), and a written cue is held to 20 / 20 / 12 words; two founder-written Feel lines (Lateral Raise, Romanian Deadlift) run longer and are named in the test.
4. **Display.** Three labelled rows (label column, then text), the drive verbs of an Action line in bold (regex, Action only; a hyphenated name like "push-up" is not a verb). A draft shows its action lines under one "Action" label.
5. **Thumbnails.** `ExerciseThumb` (32px, first frame only, no animation) beside each row in the exercise picker, each Builder prescription row and each matched line of the /check parse list; an exercise with no drawing gets an empty square of the same size. The manifest and files are the ones ARCH-073 shipped: no new image files, no schema change. The 480px WebP is scaled to 32px (about 8 KB each, `loading="lazy"`).
6. **Picker.** A native `<option>` cannot hold an image, so the `<select>` became a listbox (`role="listbox"`, `aria-label="Choose an exercise"`, four 44px rows visible and a scroll, one line per row with the name truncated). Search, Enter, Escape and the Add button work as before; ArrowUp/Down move the selection. The same component serves the Builder and /check.
